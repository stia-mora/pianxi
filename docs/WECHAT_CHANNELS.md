# 微信视频号下载

## 工作方式与条件

片析通过 [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel) 的分享解析 API 接入微信视频号。研究版本为 `1d494115df37320c6bf524baf1977dc669797d5c`。参考源码已 clone 到开发机 `output/references/wx_channel`（不随片析发布）。

上游程序依靠微信电脑的页面会话：通过本地代理与页面脚本读取媒体信息，通过 WebSocket 执行分享页解析，然后返回实际媒体 URL 和十进制 decode Key。视频前 128KB 使用 ISAAC64 生成的字节序列进行 XOR 解码。仅下载原始字节通常不能得到可播放 MP4。

片析实现了以下链路：

```text
视频号分享链接
  → wx_channel /api/v1/search/share/resolve
  → 从微信页面得到媒体 URL + Key
  → 片析校验媒体域名、流式限量下载
  → 解码前 128KB、校验 MP4 头
  → 原有视频播放、封面、抽帧、转写、分析和导出
```

**必须有运行 wx_channel 的微信电脑，并保持可用的视频号页面在线。** 纯 Linux 容器、普通 Cookie 文件或仅打开 wx_channel 控制台都不能提供微信页面会话。片析不会自动安装上游可执行文件、根证书或修改系统代理。

本次接入提供视频与标题、作者、时长。评论、点赞、收藏等互动指标尚未通过这个连接采集，页面保持“未提供”，不会从其他字段推算。

## 微信电脑的准备

1. 按上游 [README](https://github.com/nobiyou/wx_channel#readme) 安装、运行 `wx_channel`。由电脑使用者按上游说明配置其代理/证书，并了解这些设置的影响。
2. 使用支持 `/api/v1/search/share/resolve` 的版本，保持微信登录并打开视频号分享页。只启动程序还不够。
3. 如不使用上游 Insight 管理，可根据上游配置设置 `cloud_enabled: false`，本次片析接入调用的是 wx_channel 本身的 HTTP API。
4. 默认 HTTP API 根地址为 `http://127.0.0.1:2025`。上游配置 `secret_token` 时，在片析填写相同的连接令牌。不要把令牌放进 URL 查询参数。

参考提交存在令牌未传给页面的问题，可能出现页面已有下载按钮、API 在线但始终没有可用页面的情况。请按 [微信电脑端补丁构建](WX_CHANNEL_COMPANION_BUILD.md) 使用修复版，保持连接令牌鉴权；首次打开或升级后刷新视频号页面。

## 片析设置与使用

管理员进入“系统设置 → 微信视频号”，填写采集器根地址和可选令牌，点击“保存视频号连接”，再点击“检测已保存连接”。

检测会调用 `/api/v1/status`，检查 `statuses` 中 `wxchannels:sph.available`。HTTP 服务在线但没有可用分享页时会显示“尚无可用的微信分享页”，不会误报为可下载。

在首页输入框粘贴下列任一分享链接或包含该链接的分享文案：

```text
https://weixin.qq.com/sph/<分享标识>
https://channels.weixin.qq.com/finder-preview/pages/sph?id=<分享标识>
```

点击“开始分析”，任务进入现有队列。支持至多 15 分钟、500 MB 的单条视频；实际时长由下载后的 FFprobe 再校验。微信内的视频卡片、`#视频号://...` 口令、账号主页与公众号文章不是上述 HTTP 分享链接，请先取得分享页链接。

## Linux / Docker 部署

地址以**片析后端**所在机器为准，不能把开发电脑的 `127.0.0.1:2025` 直接填进远程服务器。Docker 容器里的 `127.0.0.1` 也只表示容器本身。

服务器需要经可信隧道/VPN及 HTTPS 反向代理访问微信电脑上的 HTTP API，填写对应 HTTPS 根地址。片析只需访问采集器；采集器仍在微信电脑运行。采集器不是公开互联网服务，不要直接把未经认证的 2025 端口开放公网。

Docker Desktop 下，如果采集器监听了宿主机可达地址，可用 `http://host.docker.internal:2025`；这只解决容器到宿主机的连接，不保证微信页面就绪。Linux 如需该名称，应单独配置 `host-gateway` 映射，并检查宿主机监听地址和访问控制。

连接信息保存在片析的持久化数据库，可随新的私密配置包导出（`wechat_bridge_url`、`wechat_bridge_token`）。迁移后应重新设置适合服务器的地址。原先生成的私密包没有这些后来新增的字段，在系统设置补填即可。

## 常见问题

| 提示 | 处理 |
| --- | --- |
| 请管理员连接 wx_channel | 先保存采集器地址 |
| 无法连接采集器 | 检查微信电脑程序、服务器网络、容器与宿主机地址 |
| 鉴权失败 | 核对 `secret_token`，令牌留空默认保留，清除需勾选对应选项 |
| 缺少解析 API | 更新到提供分享解析 API 的 wx_channel 版本 |
| 微信页面未就绪 | 保持已登录、可执行分享解析的视频号页面在线 |
| 媒体地址过期 / 403 | 在微信重新打开原视频，重新采集；不复用旧 CDN URL |
| 文件校验失败 | 不会将未解码数据发布为 MP4，检查采集器是否返回完整字符串 Key |

下载只允许视频号媒体域名及封面域名，并逐次检查重定向与地址；拒绝任意外部域名和内网目标。采集器的连接令牌、媒体下载令牌和 decode Key 不写入任务结果、报告或普通 API 响应。

## 验证范围

- ISAAC64 全长 128KB 与独立 uint64 C 实现交叉校验，覆盖 Key 为 0、1、大于 JavaScript 精度范围的整数及 uint64 最大值。
- 模拟与上游实际结构一致的分享解析响应，验证 HTTP 下载、令牌隔离、解码、文件大小与时长限制、重定向和内网拦截。
- 使用真实 FFmpeg 生成的加密 MP4 样本验证下载后可由 FFprobe 读取、生成封面和抽帧。
- 2026-10-15 使用授权微信电脑与补丁版 wx_channel 实测用户分享链接：解析到「零号码农」的《马斯克的 Grok Bot，到底能替你干什么？》，下载并解码为约 4.44 MB 的 MP4；FFprobe 检测为 79.21 秒、576×1024、有音轨，并完成封面与抽帧。片析通过正常任务队列执行。
- 没有在线微信页面和用户提供的真实分享链接时，不视为真实平台端到端验收完成。服务器 IP 和微信页面版本也可能影响解析，需要在实际环境确认。
